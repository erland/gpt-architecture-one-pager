# Recommended GPT Capabilities

Recommended enabled capabilities:

## Web browsing

Enable web browsing if available.

Reason:
Architecture one-pagers often require current information about:
- product capabilities
- licensing and pricing direction
- vendor strategy
- market adoption
- security advisories
- regulatory changes
- maturity and ecosystem
- current industry trends

## Code interpreter / advanced data analysis

Optional.

Useful if the user wants:
- a batch of one-pagers generated from a CSV or spreadsheet
- scoring or weighted comparison across technologies
- radar categorization across many items
- downloadable Markdown, DOCX or ZIP outputs

## File uploads

Recommended if the user wants to provide:
- internal architecture principles
- technology radar definitions
- strategy documents
- procurement rules
- security requirements
- existing standards
