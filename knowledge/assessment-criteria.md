# Assessment Criteria / Bedömningskriterier

Use these criteria when evaluating a topic. Translate criteria labels into the user's language in final output.

## Strategic relevance / Strategisk relevans

Questions:
- Does it support known strategic goals?
- Does it enable modernization?
- Does it reduce long-term complexity?
- Does it align with target architecture?
- Does it improve resilience, security, interoperability or delivery speed?

## Architectural fit / Arkitektonisk passform

Questions:
- Does it fit existing architecture principles?
- Does it introduce new platform dependencies?
- Does it simplify or complicate integration?
- Does it affect data ownership or data flows?
- Does it require new runtime or operational capabilities?

## Maturity / Mognad

Questions:
- Is it widely adopted?
- Is it supported by stable standards?
- Is the ecosystem healthy?
- Are skills available?
- Are known failure modes understood?

## Security and compliance / Säkerhet och regelefterlevnad

Questions:
- What data is processed?
- Where is data stored?
- How is access controlled?
- Is auditability sufficient?
- Are there supply-chain risks?
- Does it affect regulatory obligations?

## Operational readiness / Operativ beredskap

Questions:
- Who will own it?
- Who will operate it?
- How will incidents be handled?
- How will upgrades be managed?
- What monitoring and logging are required?

## Cost and sourcing / Kostnad och sourcing

Questions:
- Are costs predictable?
- Is licensing clear?
- Is procurement feasible?
- Does it create vendor lock-in?
- Is there an exit strategy?

## Organizational readiness / Organisatorisk beredskap

Questions:
- Are skills available?
- Are new roles required?
- Does it require cultural change?
- Is leadership sponsorship needed?
- Can adoption be incremental?
