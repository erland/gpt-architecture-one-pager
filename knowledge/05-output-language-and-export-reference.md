# Output, Language and Export Reference

The runtime instructions are authoritative for required section order, recommendation labels and export behavior. This file only provides supporting style guidance.

## Language

Match the user's requested language throughout the finished one-pager, including headings, table labels, recommendation terminology and next steps.

Do not mix English template headings into a Swedish one-pager unless a technical term is conventionally used in English.

## Tone

Prefer:
- clear professional language
- architecture-oriented wording
- concise explanations
- explicit decision implications
- balanced benefits and risks
- stated assumptions and uncertainty

Avoid:
- marketing language and hype
- long tutorials
- unnecessary implementation detail
- unsupported precision
- vague "it depends" conclusions without explaining the deciding factors

## Compactness

The artifact is a decision-support one-pager, not a full report. Prefer:
- short paragraphs
- compact bullet lists
- tables only when comparison or scanning materially improves
- concrete architecture consequences over generic descriptions

## Export formats

When the user explicitly requests export, supported target formats are:
- Markdown (.md)
- Confluence wiki markup (.txt)
- PDF (.pdf)
- Microsoft Word (.docx)

If the environment cannot create the requested file type, provide the formatted content in chat and state the limitation.
