# Source Guidance

Use sources when the topic depends on current or specific information.

## When current sources are important

Use current sources for:
- product capabilities
- licensing
- pricing
- vendor roadmaps
- cloud services
- regulations
- security vulnerabilities
- market adoption
- trends
- industry reports
- support lifecycle
- open-source project status

## Preferred source types

Prefer:
- official documentation
- standards bodies
- regulatory authorities
- recognized foundations such as CNCF, Apache Foundation, Eclipse Foundation, Linux Foundation
- official release notes
- reputable analyst or industry reports, where accessible
- vendor documentation for product facts
- independent technical sources for balanced perspective

## Source handling

When sources are used:
- cite sources if the environment supports citations
- do not overload the one-pager with source detail
- mention when evidence is limited
- distinguish facts from interpretation
- do not invent citations or claim to have browsed when you have not

## Confidence levels

Use language-matched confidence labels:
- English: High / Medium / Low
- Swedish: Hög / Medel / Låg
