# Topic Classification and Focus Reference

This file is supporting reference material. It does **not** redefine the runtime workflow, required output structure or recommendation model in the main instructions.

Use it only to deepen classification and choose the most relevant emphasis for a topic.

## Technology / Teknologi

Examples: Kubernetes, Kafka, GraphQL, WebAssembly, OpenTelemetry, OAuth 2.0.

Useful focus areas:
- technical capability and constraints
- architecture patterns enabled
- integration impact
- runtime and operational complexity
- ecosystem and standards
- lifecycle and maintainability

## Framework / Ramverk

Examples: Spring Boot, React, Quarkus, Angular, .NET Aspire.

Useful focus areas:
- development model
- ecosystem and maintainability
- skills and developer experience
- testing model
- runtime implications
- dependency and lifecycle management

## Platform / Plattform

Examples: Azure, OpenShift, Databricks, Snowflake, ServiceNow, GitHub platform.

Useful focus areas:
- strategic fit and operating model
- governance and identity/access
- vendor dependency and exit strategy
- procurement and cost control
- integration and data implications
- lifecycle and support model

## Product / Produkt

Examples: GitHub Copilot, Backstage, Jira, SonarQube, HashiCorp Vault.

Useful focus areas:
- value proposition and use cases
- product maturity and support model
- licensing and sourcing
- integration and data handling
- security and compliance
- vendor dependency and alternatives

## Method / Metod

Examples: Event Storming, Domain-Driven Design, Team Topologies, Wardley Mapping, Architecture Decision Records.

Useful focus areas:
- problem addressed
- prerequisites and roles
- facilitation/adoption approach
- organizational impact
- failure modes
- measurable outcomes

## Architecture practice / Arkitekturpraktik

Examples: Platform Engineering, API Governance, Zero Trust Architecture, InnerSource, Continuous Architecture.

Useful focus areas:
- operating and governance model
- organizational design
- enabling capabilities
- technical foundation
- adoption path
- ownership and accountability

## IT trend / IT-trend

Examples: AI Agents, Sovereign Cloud, Green Software, FinOps, Composable Architecture.

Useful focus areas:
- market and industry drivers
- maturity and evidence
- hype versus durable value
- strategic implications
- signals to monitor
- likely time horizon

## Mixed topics / Blandade ämnen

Some subjects span several categories. Select one dominant classification in the runtime output. Use a secondary lens only when it materially improves the analysis.

Examples:
- Backstage can be viewed as a product with platform-enabling characteristics.
- Platform Engineering can be viewed primarily as an architecture practice with trend characteristics.
- Kubernetes is normally a technology even when assessed as part of a platform strategy.
