# Architecture One Pager Template — English

Use this template when the user asks in English.

# [Topic] — Architecture One Pager

## Executive summary

A short, decision-oriented summary in 3–5 sentences.

Include:
- what the topic is
- why it matters
- whether it is relevant now
- recommended action

## Classification

- Type: Technology / Framework / Platform / Product / Method / Architecture practice / Trend
- Maturity: Emerging / Growing / Established / Declining / Unclear
- Recommended position: Adopt / Trial / Assess / Hold
- Confidence: High / Medium / Low

## What it is

Explain the topic in plain architectural language.

## Why it matters

Explain why architects should care.

Consider:
- business capability impact
- delivery speed
- resilience
- interoperability
- compliance
- cost control
- modernization
- security
- developer productivity

## Typical use cases

List 3–6 realistic use cases.

For methods and trends, describe use contexts rather than technical deployment scenarios.

## Architecture impact

Cover:
- application architecture
- integration architecture
- data architecture
- security architecture
- platform and operations
- governance and lifecycle

## Strengths

List practical strengths.

Each strength should explain why it matters.

## Limitations and risks

Include:
- technical risks
- operational risks
- organizational risks
- vendor or ecosystem risks
- adoption risks
- compliance risks where relevant

## Security, compliance and governance

Discuss:
- identity and access
- auditability
- data protection
- regulatory fit
- supply chain risk
- procurement implications
- policy and standards impact

## Maturity and ecosystem

Assess:
- adoption level
- ecosystem strength
- skills availability
- standardization
- support model
- long-term viability

## Fit for public-sector / enterprise context

Consider:
- transparency
- auditability
- procurement
- information security
- data sovereignty
- interoperability
- lifecycle responsibility
- accessibility and inclusiveness where relevant

## Recommendation

Choose one:

| Position | Meaning |
|---|---|
| Adopt | Suitable for broader use now |
| Trial | Run controlled pilot or limited rollout |
| Assess | Investigate further before pilot |
| Hold | Do not prioritize now |

Explain the recommendation.

## Suggested next steps

Give 3–5 concrete next steps.

## Sources and confidence

If current sources are used:
- summarize the source basis
- cite where possible
- state confidence level
- identify open questions
