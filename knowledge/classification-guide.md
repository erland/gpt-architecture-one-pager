# Classification Guide

Before writing the one-pager, classify the requested subject.

## Technology / Teknologi

Examples:
- Kubernetes
- Kafka
- GraphQL
- WebAssembly
- OpenTelemetry
- OAuth 2.0

Focus:
- technical capability
- architecture patterns enabled
- integration impact
- operational complexity
- ecosystem
- maturity
- standards

## Framework / Ramverk

Examples:
- Spring Boot
- React
- Quarkus
- Angular
- .NET Aspire

Focus:
- development model
- ecosystem
- maintainability
- skills
- testing
- runtime implications
- dependency and lifecycle management

## Platform / Plattform

Examples:
- Azure
- OpenShift
- Databricks
- Snowflake
- ServiceNow platform
- GitHub platform

Focus:
- strategic fit
- operating model
- vendor lock-in
- governance
- procurement
- identity and access
- integration
- cost control
- exit strategy

## Product / Produkt

Examples:
- GitHub Copilot
- Backstage
- Jira
- SonarQube
- HashiCorp Vault

Focus:
- value proposition
- product maturity
- support model
- licensing
- integration
- security
- data handling
- vendor dependency
- alternatives

## Method / Metod

Examples:
- Event Storming
- Domain-Driven Design
- Team Topologies
- Wardley Mapping
- SAFe
- Architecture Decision Records

Focus:
- problem addressed
- roles and facilitation
- prerequisites
- adoption approach
- organizational impact
- failure modes
- measurable outcomes

## Architecture practice / Arkitekturpraktik

Examples:
- Platform Engineering
- API Governance
- Zero Trust Architecture
- InnerSource
- Continuous Architecture

Focus:
- operating model
- governance model
- organizational design
- enabling capabilities
- technical foundation
- adoption path

## IT trend / IT-trend

Examples:
- AI Agents
- Sovereign Cloud
- Green Software
- FinOps
- Composable Architecture

Focus:
- market and industry drivers
- maturity
- hype vs durable value
- signals to monitor
- strategic implications
- time horizon
- recommendation for monitoring or experimentation

## Mixed topics / Blandade ämnen

Some topics belong to several categories. For example:
- Backstage can be treated as both product and platform-enabling framework.
- Platform Engineering is both a trend and an architecture practice.
- Kubernetes is a technology but also part of a platform strategy.

When mixed:
1. State the classification.
2. Select the dominant lens.
3. Mention secondary lenses where useful.
